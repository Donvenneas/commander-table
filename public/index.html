Commander Table

Play Magic against AI pilots, with friends, or on your own.

Seat four decks

Paste a deck link from Archidekt, Moxfield, MTGGoldfish or TappedOut. You can also paste a plain decklist, or leave a seat empty to get a random deck built from Scryfall's EDHREC rankings.

Self-test
Moxfield links don't import? Use this bookmarklet

Moxfield blocks downloads from other programs, but a bookmarklet runs inside your own browser tab on moxfield.com. Drag this button to your bookmarks bar. Then open any Moxfield deck, click the bookmark, and paste into a seat here.

Sideboard

Click a card to move one copy between your deck and your sideboard.

Batch test

Plays many games at full speed with the four seated decks and reports how each deck does. The game on the table pauses while this runs.

cEDH meta

Live data from EDHTop16 (tournament results and decklists from the last three months) and the cEDH Decklist Database (the community's curated archetypes). Choosing a seat loads the newest top-16 tournament list for that commander; the seat is set to bracket 5.

Invite players

Send each friend the link for their seat. They open it in any browser (computer, tablet or phone) on the same Wi-Fi or network as this PC; nothing to install. The game starts right away, and each seat's decisions wait for its player. If someone doesn't answer within two minutes, the AI decides for them. If the link doesn't load, allow Commander Table through Windows Firewall on private networks.

Puzzles

You get one turn, starting in your first main phase. Win it. Puzzles are small files: save any game's board with Save board as puzzle on the timeline, and load boards that others share.

Make a puzzle

Seat 1 gets one turn from its first main phase. One card per line; add *tapped* or (+2) for a tapped card or +1/+1 counters, like Grizzly Bears *tapped* (+1). Names are checked against Scryfall when you test it.

Draft / Sealed

Open packs from a real set (card lists from Scryfall) or from a cube, with three AI players. Decks are 40 cards. Play them as a Commander pod (a legendary creature from your pool as commander; set packs always have one) or one on one, best of three at 20 life, with the rest of your pool as your sideboard.

Updates

This version: …

Paste the address of a .zip with a newer Commander Table (for example a GitHub release download link). Nothing is checked or installed automatically; only use an address you trust, because its files replace the game's code. Your data folder (decks, history, settings) is never touched, and every replaced file is backed up to data\update first.

Card sets

Checks Scryfall for new and upcoming Magic sets (once a day when the game starts, and whenever you click). When a new set is out, saved card data is fetched again as decks need it (legalities and Standard rotation change), and the newest sets show up in Draft / Sealed and the Expedition.

Card file

Keeps Scryfall's free card file (every card, about 25 MB to download, about 40 MB saved) in the game's browser data. Random decks, the deck builder and loading decks by card name then work without asking Scryfall card by card, and offline. When it's on, a newer file is fetched at most once a day at startup. Searches it can't answer (a set's cards, other printings) still ask Scryfall.

Learn to play

Seven short lessons, one turn each, with a coach beside the table. Start at the top; each takes a minute or two.

The Lantern Road

An original story in four chapters. Each chapter is a whole game, one on one, from a special starting board. Win to open the next.

Expedition

A solo roguelike in three acts. Choose a road at each step: duels, elite rivals, events and rest stops, then a boss at the end of each act. Win a fight to take a card for your deck; lose and the expedition is over. Nothing to buy: rewards are cards for this run only.

Challenge links

A challenge is this table's setup (format, match length, each seat's name, style, bracket and deck) packed into a link or a code. Nothing is stored online: everything is in the text. Anyone running Commander Table can open the link on their PC, or paste the code here.

Tabletop Nothing is automated: click a card for its moves, use the buttons for life, draws and turns.

Stops

When you play a seat, the game normally stops only when you can do something: your main phases, attacks and blocks, and responses when you have a card to cast. Choose more places to stop here, for every seat you play on this PC. Changes apply from the next game (a game keeps the stops it started with, so undo and replays stay exact).

Deck library

Decks saved in this game folder (data\decks), so they come along when the folder is copied to another PC.

Tournament

Enter five or more decks. Put each link (or random) on its own line; separate pasted decklists with a line containing only ---. Every round, the decks are shuffled into pods of four; any left over sit that round out. Each pod plays several games at full speed. Points per game: 3 for first, 2 for second, 1 for third.

Exit Commander Table?

This stops the current game and shuts down Commander Table. To play again later, open Commander Table (or run start.bat).
